Repositorio personal con las **notas estructuradas** de todos los laboratorios realizados durante la preparación de la certificación **eLearnSecurity Junior Penetration Tester (eJPT)** de **INE**.

Cada archivo `.md` contiene:
- 🔍 Procedimientos paso a paso.
- 💻 Comandos exactos utilizados.
- 📊 Salidas de terminal esperadas.
- 🧠 Explicaciones de los conceptos clave.
- 🏁 Banderas capturadas en los CTF.
